# Проверка по ученическия наръчник

- [x] Налични профил и частно хранилище — създадени от автора.
- [x] README с тема, автор, клас, цел, текущ етап и връзка към Notion.
- [x] Пет папки с README и ясно предназначение.
- [x] Пренесени вече готови задачи с източници и ограничения.
- [x] Първа едностранична пробна версия в DOCX и PDF.
- [ ] Втора версия със същите имена и добавен абзац за очаквания резултат.
- [x] Дневник с промени, причини и следваща задача.
- [ ] Покана към преподавателя — необходим е точният GitHub username.
- [ ] Приета покана и потвърден достъп на преподавателя.
- [ ] Предаване в Classroom — липсва конкретно задание за предаване.

## Как се доказват версиите

Отвори Commits и записа „Добавени структура, готови материали и първа пробна версия“. Файловете 03-razrabotka/proben-dokument.docx и .pdf съдържат първата версия. Следващият запис „Добавен очакван резултат към пробния DOCX и PDF“ трябва да съдържа втория абзац. Отвори Browse files за съответния запис или History на конкретния файл. DOCX и PDF могат да се изтеглят и сравнят.

## Какво остава

Добавяне на потвърденото име на ръководителя; покана до точния му GitHub профил; проверка след приемане; предаване на адреса на хранилището и точния commit в Classroom според уговорката. Няма изпратени покани или извършено предаване.

Източници: предоставеният ученически наръчник, оригиналният Notion план и общият документ с изпълнените задачи. Втората пробна версия е упражнение и не е доказателство за проведена анкета, финансов анализ или завършена дипломна работа.
